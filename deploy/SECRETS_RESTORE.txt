How to restore for deploy
-------------------------
Option A (compose from this repo):
1. Copy the private .env to:
   /home/anhtri/open-webui/deploy/.env
2. Start from the repo deploy folder:
   docker compose -f /home/anhtri/open-webui/deploy/docker-compose.yml up -d --build

Option B (legacy live path):
1. Keep/copy the private .env at:
   /home/anhtri/open-webui-deploy/.env
2. If using this path, make sure the launcher/compose command passes that file as env_file.

Safety rules
------------
- Never commit deploy/.env or /home/anhtri/open-webui-deploy/.env.
- Never print WEBUI_SECRET_KEY or Cloudflare tunnel token.
- Do not bind this Open WebUI service on 0.0.0.0, 3000, or host 8080.
- Do not mix this deploy with ~/LLM-deploy.
- Skills are kept in /home/anhtri/open-webui/skills/ for future deploy/import.
